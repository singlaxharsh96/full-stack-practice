# React Practice Task

This project completes all four React practice activities from the supplied task sheet:

1. Counter App – `useState`
2. Student Profile – `useRef`
3. Student Portal – React Router
4. Task Manager – `useState` + `useRef` + React Router

## How to run

Open this folder in VS Code and run:

```bash
npm install
npm run dev
```

Then open the local address shown by Vite in the terminal.

## Build check

```bash
npm run build
```

## Main files

- `src/App.jsx` – main routing and navigation
- `src/pages/Counter.jsx` – Practice 1
- `src/pages/Profile.jsx` – Practice 2
- `src/pages/Portal.jsx` – Practice 3
- `src/pages/TaskManager.jsx` – Practice 4
- `src/styles.css` – simple student-level styling
